**lights-out 0.8.1** adds a start with nothing installed and two plain git hooks, and fixes three things that cost hours or a false NO-GO. It adds no command and no flag.

- **From zero to hero, with nothing installed** ([ADR 0097](https://github.com/nicolaguglielmi/lights-out/blob/v0.8.1/docs/adr/0097-from-zero-to-hero-and-a-start-with-nothing-installed.md)).
  - The tutorial opens with seven levels, each ending on a real `GO`.
  - An Open in Codespaces button in the README starts a dev container that runs `./go demo`. Proven on Actions: 668 s to the rollback.
  - The site's first screen is the frozen console of a real run.
- **Plain git hooks** ([the guide](https://github.com/nicolaguglielmi/lights-out/blob/v0.8.1/docs/use-on-your-repo.md#plain-git-hooks)). With git alone, a `pre-commit` runs the light tier on what the commit stages, `commit -a` included, and a `pre-push` runs the full gates on each branch the push sends. Verified on a Mac; `core/tests/test_git_hooks.py` runs both from the guide's text on every `./go ci`.
- **The gates image waits for a `.git` file a podman machine shows late.** On macOS, for 4 to 5 s after a commit or a `git switch`, the container did not see `.git/HEAD` or the branch's ref, and `lights-out gates` answered `NO-GO: gates — the current directory is not a git repository with a commit`. The image now waits for HEAD, up to 15 s, with one line on stderr.
- **The mutation runner stops with one line** ([ADR 0076, amendment](https://github.com/nicolaguglielmi/lights-out/blob/v0.8.1/docs/adr/0076-a-mutant-runs-the-tests-that-reach-it.md)). A Python suite that passes without the coverage hook and fails with it used to turn test selection off quietly, so every mutant ran the whole suite. That cost hours twice. The runner now stops before any mutant and says why. `MUTATION_SELECT=off` is still the explicit way to run the whole suite.
- **DAST scans the stable again when its report lost whole paths** ([ADR 0072, amendment 2026-11-17](https://github.com/nicolaguglielmi/lights-out/blob/v0.8.1/docs/adr/0072-security-scanning-sast-sca-dast-sbom.md)). If every new canary alert is on a path the stable's report has nothing for, the stable is scanned once more, and the canary is judged against both reports. This flake was measured once in 203 jobs.
- **Fixes and proofs:**
  - `stranger` runs `./go try` after the demo, on a copy of `workloads/minimal-js` with no contract, and the tutorial's level 2 quotes that run;
  - the site's frozen console follows main again: it comes from the ci run that judged main's commit, on any branch ([ADR 0089, amendment](https://github.com/nicolaguglielmi/lights-out/blob/v0.8.1/docs/adr/0089-a-read-only-console-snapshot.md));
  - the README and the guide state what M24 proved on tenacity, and the tutorial says the intake's confirm needs the plane.
