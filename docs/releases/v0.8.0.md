**lights-out 0.8.0** makes the first run hassle-free, adds GLM as a fourth provider, screens requests before any agent reads them, and lets lights-out sit on your delivery instead of its own.

- **The first run, flawless** ([ADR 0093](https://github.com/nicolaguglielmi/lights-out/blob/v0.8.0/docs/adr/0093-the-first-run-flawless.md)).
  - A preflight starts a stopped podman machine and moves busy ports by itself. A busy 3000 or 8080 no longer breaks the demo.
  - `./go demo` shows seven numbered steps with estimates instead of about 3,000 lines.
  - The demo ends on the run's console, opened on the canary that rolled back.
  - On a clean runner it takes 370–480 s, against 700–805 s before.
  - `./go try <repo>` tries the gates on your own repository in one command.
- **GLM by Z.ai, and a budget per provider** ([ADR 0092](https://github.com/nicolaguglielmi/lights-out/blob/v0.8.0/docs/adr/0092-glm-by-zai-and-a-budget-per-provider.md)). `MODEL_PROVIDER=zai` runs GLM-5.3 through Claude Code on Z.ai's Anthropic-compatible endpoint, and through LiteLLM for the ADK roles. `TOKEN_BUDGET` can differ per provider. Cached input is priced at the vendor's cached rate, so M24's ten Gemini runs cost $3.55 in the ledger, not $20.85.
- **Closed decisions** ([ADR 0091](https://github.com/nicolaguglielmi/lights-out/blob/v0.8.0/docs/adr/0091-closed-decisions-the-perimeter-and-the-injection-screen.md)). A `Decide` port with two adapters: the Gemini Decisions API, or the profile's own model through structured output, so it works with any provider. It drives two things:
  - every request and ticket is screened for instructions aimed at an AI agent before any agent reads it (12 of 12 labelled injections stopped, 12 of 12 benign passed);
  - the intake can ask, file by file, which ones a ticket touches.
  Replayed at L0.
- **Your CI/CD instead of ours** ([ADR 0095](https://github.com/nicolaguglielmi/lights-out/blob/v0.8.0/docs/adr/0095-flagger-under-the-launchpads-gates-and-two-more-ci-surfaces.md)).
  - `DELIVERY=flagger` keeps Flagger's own analysis and automatic rollback, while 100% still waits for a person. Proven on k3s.
  - GitLab CI joins Jenkins as a surface, proven with a real runner.
  - The CircleCI recipe is validated and its step run; it has not run on CircleCI itself.
- **More of the harness in Python** ([ADR 0094](https://github.com/nicolaguglielmi/lights-out/blob/v0.8.0/docs/adr/0094-ci-under-the-shell-boundary-later.md)). The harness conformance suites and the toolchain check moved to Python with unit tests, and left the shell debt list. `ci/`'s debt is measured, and it joins the ratchet next.
- **Fixes:**
  - antigravity-cli now counts Gemini's cached tokens;
  - the jenkins job runs the commit's own gates image;
  - a test that broke the mutation runner's coverage hook is fixed.
