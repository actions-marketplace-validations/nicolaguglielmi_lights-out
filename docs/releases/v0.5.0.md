**lights-out 0.5.0** adds security scanning to the gates and to the release, and is the first release cut by its own tag.

- **SAST judges the diff** ([ADR 0072](https://github.com/nicolaguglielmi/lights-out/blob/v0.5.0/docs/adr/0072-security-scanning-sast-sca-dast-sbom.md) §1). A finding the base already had is listed, never blocking; a finding the change adds is a NO-GO. A repository with an old `assert` or a jitter `random` no longer waits for a human to add `# nosec`. `SAST_CMD` now prints `items`; a runner that does not keeps the whole-tree verdict until `lights-out init` refreshes it.
- **An SPDX 2.3 SBOM per released image** (§2), made by the pinned osv-scanner and attested with cosign beside the signature: `cosign verify-attestation --type spdxjson`.
- **Passive DAST at staging** (§3, §4): ZAP's baseline scan on the stable and on the canary before any traffic, NO-GO only for an alert the canary raises and the stable does not. Off by default (`DAST=off`): its cold pull would take the first `./go demo` past 15 minutes. `./go demo-dast` shows both verdicts.
- **The tag releases itself** ([ADR 0075](https://github.com/nicolaguglielmi/lights-out/blob/v0.5.0/docs/adr/0075-the-tag-releases-itself.md)): the wheel to PyPI by trusted publishing, the two Action repositories synced, the drafts written, and the wiki rendered from the repository at the tag ([ADR 0077](https://github.com/nicolaguglielmi/lights-out/blob/v0.5.0/docs/adr/0077-the-wiki-is-rendered-at-the-tag.md)).
- **Faster mutation testing in `self`**: a mutant runs only the tests that reach it ([ADR 0076](https://github.com/nicolaguglielmi/lights-out/blob/v0.5.0/docs/adr/0076-a-mutant-runs-the-tests-that-reach-it.md)).
