# 0021 — A one-line size report of the metrics page (main-always-green demo, 2 of 3)

- Status: open
- Labels: feature, app/backend, M30 (main always green demo)
- Found: 2026-11-07, designing `./go demo-mainline` (docs/adr/0056 §7)

## Problem

The ops runbook asks how big the metrics page is before a scrape config
changes. Nothing in the app answers that in one line.

This ticket is one of the three `./go demo-mainline` runs together with
0020 and 0022. Judged alone on its base it is GO; merged after 0020, which
renames the function it calls, it breaks main. The main check finds its
merge by bisection and reverts it.

## Acceptance criteria

Given the app has served at least one request
When `meetups.report.metrics_report()` is called
Then it returns `<bytes> bytes, <lines> lines` for the metrics page as the
app renders it at that moment.

Given that change
When the test suite runs (`./go test`)
Then a test checks both numbers on a page of known size.

## Perimeter

- `app/backend/meetups/report.py`
- `app/backend/tests/test_report.py`

## Notes for the implementer

- Low risk: no migration, no auth, no platform path.
- At L0 the change is a hand-written fixture (`fixtures/0021/dev-worker/`,
  `run.json` says `hand_written: true`); the gates, the tower and the
  main check that judge it are real.
