# 0012 — A meetup can be created with a capacity below one, and then nobody can register

- Status: open
- Labels: bug, app/backend, network (docs/adr/0036): the first ticket split between two members
- Found: 2026-11-03, writing the agentic-network plan (`docs/plans/agentic-network.md`)

## Problem

`POST /api/meetups` accepts any integer `capacity`, including `0` and
negative numbers. The registration route compares the number of
registrations with the capacity, finds `0 >= 0`, and answers
`409 {"detail":"meetup is full"}` (or `501` while the `waitlist` flag is
on) to the very first person who tries. The meetup exists, is listed,
and can never be joined.

## Acceptance criteria

Given a logged-in user
When they post a meetup with `capacity` `0`, or a negative number, to
`POST /api/meetups`
Then the response is `422`, and no meetup is created: `GET /api/meetups`
does not list it.

Given a logged-in user
When they post a meetup with `capacity` `1`
Then the response is `201` and the body's `capacity` is `1`: the
smallest valid capacity is one.

Given `app/README.md`'s row for `POST /api/meetups`
When this ticket lands
Then it says that `capacity` must be at least 1 and that a lower value
answers 422.
